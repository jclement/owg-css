Getting started with owg-css

owg-css is one stylesheet that makes plain HTML look like a well-kept terminal: dense, monospace, quiet. This page takes you from nothing to a themed docs site in about five minutes. v0.1.0 ~6 KB gzip

Install

There is nothing to install. Link the stylesheet from jsDelivr, pinned to a release:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jclement/owg-css@v0.1.0/dist/owg-fonts.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/jclement/owg-css@v0.1.0/dist/owg.min.css">

owg-fonts.css is optional: it self-hosts Roboto Mono. Leave it out and the stack falls back to your system monospace font (SF Mono, Menlo, Consolas, DejaVu).

Tip

Use @main instead of @v0.1.0 to follow the latest commit. Fine for a side project; pin a tag for anything you care about.

Prefer to vendor it? Download dist/ and fonts/ and keep them side by side so the font paths resolve.

Your first page

Write semantic HTML. A <header> directly inside <body> becomes a fixed top bar, and its first child is the title:

  1. Create index.html 
    <!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="owg.min.css">
</head>
<body>
  <header>
    <a href="/">relic<span>://</span>status</a>
    <nav><a href="/logs">Logs</a></nav>
  </header>
  <main>
    <h1>All systems normal</h1>
  </main>
</body>
</html>
  2. Open it in a browser

    No server needed; file:// works.

  3. Add classes only where Markdown can't reach

    Badges, callouts, cards, steps. See the kitchen sink.

Themes

By default the page follows the operating system's light or dark setting. To force one, set data-theme on <html>: 

<html data-theme="dark">   <!-- or "light"; omit for auto -->

To give visitors a switch that remembers their choice, add the theme helper in <head> (not deferred, so it applies before the first paint) and mark up a few buttons:

<script src="https://cdn.jsdelivr.net/gh/jclement/owg-css@v0.1.0/dist/plugins/owg-theme.js"></script>

<div role="group" aria-label="Theme">
  <button data-theme-set="auto">auto</button>
  <button data-theme-set="light">light</button>
  <button data-theme-set="dark">dark</button>
</div>
APIDoes
owgTheme.set('dark')Force auto, light or dark; saved to localStorage.
owgTheme.variant('slate')Switch variant; null for the default.
owgTheme.get(){ theme, variant } as currently applied.
owg:theme eventFired on document after every change.

Variants

A variant is a different set of colour tokens. Each one has a light and a dark form, so it combines with any theme:

<html data-variant="phosphor">
<select data-variant-select aria-label="Variant">
  <option value="">default</option>
  <option value="amber">amber</option>
  <option value="hotdog">hotdog</option>
</select>

default amber phosphor slate contrast doom hotdog

Warning

hotdog is a faithful tribute to Windows 3.1's Hotdog Stand scheme. It passes contrast checks. It does not pass taste checks.

App shell

Add an <aside> directly inside <body> and you get a fixed sidebar under the top bar. Below 960px it becomes a drawer, opened by a plain link, so it works without JavaScript: 

<header>
  <a href="#sidebar" class="sidebar-toggle" aria-label="Open menu">☰</a>
  <a href="/">owg<span>://</span>css</a>
</header>
<aside id="sidebar">
  <a href="#" class="sidebar-close" aria-label="Close menu">×</a>
  <nav>
    <h2>Getting started</h2>
    <ul><li><a href="#install" aria-current="page">Install</a></li></ul>
  </nav>
</aside>

With owg-theme.js loaded, Esc and a click outside also close the drawer.

Docs layout

Put an <article> and a <nav class="toc"> in <main>. Above 1200px the table of contents becomes a sticky right column; below that it sits above the article. This page is built exactly that way.

Tokens

Everything is a custom property on :root. Override a few to make it yours:

:root {
  --owg-font-size: 15px;      /* everything scales from here */
  --owg-radius: 0;            /* sharp corners */
  --owg-accent: #c2410c;      /* burnt orange links and buttons */
}
--owg-font-size
14px root; every size is in rem
--owg-accent
links, buttons, focus rings, markers
--owg-measure
prose line length, 78ch
--owg-sidebar-width
15rem
--owg-topbar-bg
top bar fill, separate so variants can paint it

Plugins

Three optional files, each independent:

  • owg-highlight.css: highlight.js, Prism and Shiki colours from theme tokens.
  • owg-mermaid.js: Mermaid diagrams in the current palette, re-rendered when the theme changes.
  • owg-theme.js: the theme and variant switch, plus drawer niceties.

Note

None of them is needed for the core. The stylesheet has no JavaScript and works with it switched off.
