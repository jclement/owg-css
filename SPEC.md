# owg-css — the contract

This file is the contract every part of owg-css is built against. If you change a name here,
every file that uses it changes too. Build agents: **implement this; do not rename it.** If
something here is wrong or missing, implement the best version, then say what you changed and
why in your report (and update this file in your branch).

## Goals

- **Drop-in, classless-first.** Link one stylesheet and plain semantic HTML (what Markdown
  renders) looks finished. Classes are opt-in extras, short and readable.
- **Dense, technical, monospace.** Roboto Mono, 14px root, tight rhythm, 3px corners, thin
  rules. The visual language of owg.me: zinc neutrals, one cool accent, `//` section labels,
  terminal/prompt touches, quiet surfaces, no gradients, no heavy shadows.
- **Small and dependency-free.** No JS in the core. Budget: `owg.min.css` under 14 KB gzip (`mise run check`).
  Tailwind is the thing we are *not*. Plugins (highlight, mermaid, theme toggle) are separate files.
- **Accessible.** Body text and every text colour >= 4.5:1 in every theme x variant; visible
  focus rings; `prefers-reduced-motion` respected; works without JS; prints cleanly.
- **Modern-browser baseline**: last 2 years of evergreen browsers. `:has()`, `color-mix()`,
  `:where()`, nesting-free (write flat CSS; no CSS nesting).

## Theming

- Tokens live in `src/tokens.css` (all `--owg-*`). **Never hard-code a colour anywhere else**;
  use tokens (and `color-mix()` on tokens).
- Theme: auto via `prefers-color-scheme`; force with `<html data-theme="light|dark">`.
- Variant: `<html data-variant="amber|phosphor|slate|contrast|doom|hotdog">` (default: none = owg
  zinc/sky). Files in `src/variants/`. Variants only override tokens. `hotdog` is Jeff's
  request (Windows 3.1 Hotdog Stand): yellow page, red top bar, black rules.
- The top bar has its own tokens (`--owg-topbar-bg/-text/-title/-accent/-border`) so a
  variant can colour it independently (hotdog does). Layout must use them, not surface/text.
- Use `:where()` for element defaults so author CSS wins easily (keep specificity low).

## Markup contract

### Page skeleton (classless)

```html
<html lang="en" data-theme="dark" data-variant="slate">   <!-- both attributes optional -->
<body>
  <header>                                   <!-- body > header = fixed top bar -->
    <a href="/">owg<span>://</span>css</a>   <!-- first child = the page/site title -->
    <nav>                                    <!-- links, right-aligned -->
      <a href="/docs/">Docs</a>
      <a href="https://github.com/...">GitHub</a>
    </nav>
    <!-- anything else (a theme toggle button) sits at the far right -->
  </header>
  <main> ... </main>                          <!-- centred, max --owg-container -->
  <footer> ... </footer>                      <!-- body > footer = muted, thin rule above -->
</body>
```

- The title (`body > header > :first-child`, typically `<a>`, `<strong>` or `<span>`) is
  bold, `--owg-text-strong`; a `<span>` inside it is drawn in the accent (`owg<span>://</span>css`).
- `nav` may hold bare `<a>`s or a `<ul><li><a>` list; `aria-current="page"` marks the active link.
  On narrow screens the nav scrolls sideways (faded right edge); the title never truncates.
- Buttons/selects in the bar are drawn quiet (transparent, `--owg-topbar-*` colours), sized to it.
- The top bar is `position: fixed`, `--owg-topbar-height` tall, translucent `--owg-topbar-bg`
  with backdrop blur, a bottom border. `body` gets `padding-top` so content is not hidden, and
  `scroll-padding-top` so anchor jumps land below it.
- Pages without `body > header` get no top bar and no padding.

### App shell: top bar + sidebar (classless, via `:has()`)

```html
<body>
  <header>
    <a href="#sidebar" class="sidebar-toggle" aria-label="Open menu">☰</a>  <!-- shown < 960px -->
    <a href="/">owg<span>://</span>css</a>
    <nav>...</nav>
  </header>
  <aside id="sidebar">                       <!-- body > aside = fixed left sidebar -->
    <a href="#_" class="sidebar-close" aria-label="Close menu">×</a>  <!-- shown < 960px -->
    <nav>
      <h2>Getting started</h2>               <!-- any h2-h6 or <p> = group label -->
      <ul>
        <li><a href="#install" aria-current="page">Install</a></li>
        <li><a href="#usage">Usage</a>
          <ul><li><a href="#themes">Themes</a></li></ul>   <!-- nested = indented, ruled -->
        </li>
      </ul>
      <details open><summary>Reference</summary><ul>...</ul></details>  <!-- collapsible group -->
    </nav>
  </aside>
  <main> ... </main>
  <footer> ... </footer>
</body>
```

- `body:has(> aside)` switches on the shell: sidebar fixed under the top bar, own scroll,
  `--owg-sidebar-width` wide; `main` and `footer` shift right.
- Under 960px the sidebar is an off-canvas drawer opened by `#sidebar:target` (works with no JS;
  the `.sidebar-toggle` link opens it; `.sidebar-close` closes it, and so does a tap on the dimmed
  backdrop, which is drawn as part of the close link). Point the close link at a fragment that
  matches nothing (`href="#_"`): a bare `href="#"` also closes it but jumps to the top of the
  page. Toggle and close links are hidden on wide screens. `plugins/owg-theme.js` may enhance it (Esc, click-outside)
  but must not be required.
- Group labels look like owg.me section labels: small, muted, `//` prefix in the accent.

### Docs page: article + table of contents

```html
<main>
  <article> ...headings, prose... </article>
  <nav class="toc">                          <!-- optional, right column -->
    <h2>On this page</h2>
    <ul><li><a href="#a">Section</a><ul><li><a href="#a1">Sub</a></li></ul></li></ul>
  </nav>
</main>
```

- `main:has(> nav.toc)` becomes a two-column grid (article + sticky TOC, `--owg-toc-width`)
  above 1200px; below that the TOC sits above the article as a compact block (top-level
  entries only, flowing into columns).
- The current section is marked `aria-current="true"` (or `.active`) on its TOC link, set by a
  scroll-spy script if the page wants one (CSS cannot know it); it lights the accent rail.
- Prose width is capped at `--owg-measure`.

### Footer, grid

- `body > footer`: small muted text, top border, same horizontal alignment as `main`.
- `.grid`: responsive auto-fit columns (`min 14rem`), gap `--owg-space-4`. `.grid.cols-2/3/4`
  fixed column counts that collapse to one column under 640px.

## Non-text contrast (WCAG 1.4.11)

- Form control boundaries use `--owg-control-border` (>= 3:1 everywhere). `--owg-border`/`-strong` are for
  decorative rules only.
- Focus indicators use a solid `--owg-focus` outline (>= 3:1), never a translucent halo alone.
- `@media (forced-colors: active)`: controls, checked states, focus and the active sidebar/TOC item stay
  visible with system colours.

## Element styling (classless, core)

Typography: `h1`-`h6` (tight, h1/h2 with a hairline under h2), `p`, `a` (accent, underline on
hover, offset), `strong`, `em`, `small`, `mark` (accent-soft), `abbr`, `sub`/`sup`, `del`/`ins`,
`blockquote` (left accent rule, muted), `hr` (dashed or hairline), `ul`/`ol` (accent markers),
`dl`/`dt`/`dd` (dt bold, dd indented or a two-column grid with `dl.inline`), `kbd` (keycap:
border + bottom shadow), `samp`, `var`, `figure`/`figcaption`, `img`/`video` (responsive),
`details`/`summary` (bordered, chevron, open state), `progress`, `meter`, `iframe`.

Code: inline `code` (surface-2 chip); `pre` (surface, border, radius, horizontal scroll, no
wrap, tab-size 2); `pre > code` resets the chip. `pre[data-lang]` shows the language label
top-right (`attr(data-lang)`), muted, small caps.

Tables: dense by default, full width, `thead` bottom rule strong, row hover tint,
`tbody tr` hairlines, numeric columns via `td.num`/`th.num` (right, tabular-nums). Wide tables:
wrap in `<figure>` or `.table-wrap` to scroll horizontally. `table.striped`, `table.compact`,
`table.bordered`.

Forms: `input` (all text-like types), `select`, `textarea`, `checkbox`, `radio`,
`input[type=checkbox][role=switch]` (toggle switch), `range`, `color`, `file`, `fieldset`/
`legend`, `label` (block above control; inline when wrapping a checkbox/radio), helper text
via `<small>` after the control, `[aria-invalid="true"]` (danger) and `[aria-invalid="false"]`
(success), `:disabled`, `:focus-visible` ring. `form .row` or `.grid` for side-by-side fields.
`<input>`+`<button>` inside `[role=group]` render as one joined control.

Buttons: `button`, `input[type=submit|button|reset]`, `a.button`/`[role=button]`. Default =
accent fill. Modifiers: `.secondary` (surface + border), `.outline` (transparent + accent
border), `.ghost` (text only), `.danger`, `.small`, `.large`; `[aria-busy="true"]` shows a
spinner; `[disabled]`. `[role=group]` joins buttons.

## Components (opt-in classes)

- **Badge**: `<span class="badge">v1.2</span>`; colours `.accent .blue .green .amber .red
  .purple .pink .cyan` (default neutral). Soft tint bg + coloured text + faint border.
  `.solid` = filled. `.dot` = leading status dot. Works inside headings, tables and links.
- **Callout**: `<aside class="callout note">` with optional first child
  `<p class="callout-title">Note</p>`; types `note tip important warning danger` (+ aliases
  `info`=note, `success`=tip, `caution`=danger). Left rule + tinted bg + icon-ish glyph in the
  title (CSS-only, text glyphs, no icon font). `<details class="callout warning">` with
  `<summary>` as the title = collapsible. Also style GitHub-flavoured Markdown output:
  `.markdown-alert.markdown-alert-{note,tip,important,warning,caution}` with
  `.markdown-alert-title`.
- **Card**: `.card` (surface, border, radius, padding); `.card > header` / `> footer` ruled
  sections. Classless `article` is NOT a card.
- **Section label**: `.label` - owg.me's `// label ---------` divider (`//` accent, rule to the end).
- **Terminal**: `<pre class="terminal" data-title="~/code">` - window chrome bar with
  title; `<span class="prompt">$</span>` lines; `.output` muted.
- **File block**: `<figure class="file"><figcaption>src/app.ts</figcaption><pre>...</pre></figure>`.
- **Steps**: `<ol class="steps">` - numbered, connected vertical rail.
- **Tooltip**: `[data-tooltip="text"]` on any element (CSS-only, top; `data-placement="bottom"`).
- **Key-value**: `<dl class="kv">` - owg.me rows (key muted, value text, hairline rows).
- **Status / stat**: `.stat` (big number + small label), `.dot.green` status dots.
- **Avatar**: `img.avatar` (square-ish 3px radius, grayscale until hover, as owg.me).
- Components may add more (e.g. `.breadcrumb`, `.pagination`, `.empty`), documented in
  the component file's header comment and in the demo.
- Added by the components agent (markup in each file's header):
  `.cmdline` (owg.me prompt bar: `.user .host .path .cmd` spans + blinking cursor; named
  `cmdline`, not `prompt`, because `span.prompt` is the terminal's `$`), `.cursor` (blinking
  block), `nav.breadcrumb`, `nav.pagination`, `.empty`, `ul.tags` / `a.tag`,
  `.card.link` / `a.card`, `.stat small.up|.down`, `.dot.pulse`, `img.avatar.small|.large|.color`.
- Colour classes `.accent .blue .green .amber .red .purple .pink .cyan` are shared
  (`src/components/colors.css`): they only set the private `--_c` property, so they are inert
  on elements that don't paint with it.

## Plugins (optional, separate files)

- `plugins/owg-highlight.css`: maps highlight.js (`.hljs-*`), Prism (`.token.*`) and Shiki
  (`--shiki-*` css-variables theme) classes onto `--owg-syn-*` tokens. Works in every theme
  x variant with no extra config. Diff lines (`.hljs-addition`/`deletion`, `.token.inserted`)
  tinted.
- `plugins/owg-mermaid.js`: ES module and classic-script friendly. Initialises mermaid with
  `theme: 'base'` and `themeVariables` read from the live `--owg-*` tokens (font = Roboto Mono),
  renders `pre.mermaid` / `.mermaid` blocks, and **re-renders** when `data-theme`,
  `data-variant` or the OS scheme changes (keep the original source in a data attribute).
  Does not load mermaid itself if `window.mermaid` exists; otherwise takes it as an argument or
  imports from jsDelivr.
- `plugins/owg-theme.js`: tiny (< 2 KB gzip) helper. `owgTheme.set('auto'|'light'|'dark')`,
  `owgTheme.variant('slate'|null)`, persisted in localStorage (every access in try/catch),
  applied before paint when included in `<head>`; wires any `[data-theme-set]` /
  `[data-variant-set]` buttons or `<select data-variant-select>`. Enhances the sidebar drawer
  (Esc closes, click outside closes).

## Commands

- `mise run build` -> `dist/owg.css`, `dist/owg.min.css`, `dist/plugins/*`.
- `mise run dev` -> rebuild on change + static server (own herdr tab only).
- `mise run check` -> build, fail on CSS parse errors, size budget, contrast (`scripts/contrast.mjs`).
- `mise run screenshots` -> `docs/screenshots/*.png` via Playwright.
- Wrap anything heavy in `heavy` (e.g. `heavy mise run check`). One heavy job at a time.
